# RouteSphere — Project 10
Local educational logistics prototype. Run `docker compose up --build` from this directory with Docker Desktop running. UI: http://localhost:3000; API health: http://localhost:4000/health; tracking Swagger: http://localhost:8000/docs. Create a shipment, assign the seeded demo vehicle and driver, then advance its status. Use synthetic GPS events via Swagger with unique event IDs and ISO timestamps. Latest position is selected by event time, not arrival order; duplicate IDs are ignored. Route sequencing uses nearest-neighbor great-circle distance and constant speed, not road routing. Run Python tests with `docker compose run --rm tracking pytest -q`. No authentication: local synthetic data only. Redis is provisioned but unused. See docs/status.md for gaps. Docker integration not verified.
